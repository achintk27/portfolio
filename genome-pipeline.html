01 / THE PROBLEM

Why build it?

Processing chromosome datasets involves repeated parsing, filtering, and validation. This project automates those steps so raw FASTA and VCF files can become structured features for analysis.

02 / THE APPROACH

How it works.

Developed modular Python processing steps for feature extraction and variant filtering. Added input validation and structured logging to help identify processing failures, and trained models for SNP classification.

03 / THE OUTCOME

What it delivers.

Automated processing was 50% faster, with 85% SNP classification accuracy. The modular pipeline makes validation and failure diagnosis part of the processing workflow.
